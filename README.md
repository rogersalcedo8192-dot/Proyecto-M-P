# Proyecto-M&P

Landing page de M&P enfocada en automatizacion, inteligencia artificial, captacion y conversion.

## Stack

- HTML
- CSS
- JavaScript

## Estructura

- `index.html`: estructura principal de la landing
- `styles.css`: estilos visuales, responsive e interacciones visuales
- `script.js`: animaciones, efectos e interacciones
- `assets/`: logos, iconos e imagenes
- `video/`: videos usados en la experiencia

## Objetivo

Presentar la propuesta de valor de M&P con una experiencia visual futurista, premium y orientada a conversion.
